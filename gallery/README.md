# Galería nativa de Mobile Design

El catálogo abre 11 rutas. Los demos anteriores de carrusel, calendario y progreso se conservan como código de referencia.

Desde `gallery/`, instala las dependencias con `pnpm install`. Usa `pnpm android` o `pnpm ios` para preparar el cliente de desarrollo y `pnpm start` para servir el catálogo con Metro.
