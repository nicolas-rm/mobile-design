# Lists reference artwork

Exact decorative regions from the official Material3 Lists figures and clips, retrieved on2026-10-27. See `sources.json` for source URLs, media IDs, crops, dimensions, video frame times and hashes. Interactive controls, labels, device frames, touch cursors and keyboard captions remain React Native UI; none is included in the cropped assets.

The23 PNGs remain exact source-region crops. The21st Century Strangers artwork differs between G32 (beige) and G07 (pink), so both are retained. The Succulent photograph is only partially published and remains a112×66 crop; Play it as it lays remains a152×80 partial cover. Missing pixels are not reconstructed.

Source avatar PNGs are opaque and retain surrounding light source pixels. Contacts uses `source-avatar-shapes.ts` as native SVG clipping geometry for Alejandro and Sofia; `source-avatar-shapes.json` records the source hashes and contour derivation. The paths approximate the published silhouettes rather than official Material shape tokens, and do not modify the photo pixels. Inbox has its own circular Alejandro crop from G22, distinct from the expressive Contacts portrait in G12.
