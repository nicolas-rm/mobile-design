Documentation website assets: material-symbols.ttf is a local subset served by the official Google Fonts CSS API on 2026-11-03 (Material Symbols Rounded, default axes). Requested names are listed in icon-names.json. Copyright Google LLC, Apache License 2.0. It is distinct from the complete pinned package font described below. The website uses Roboto 400/500/700 under SIL OFL 1.1. Editorial illustrations are original CSS compositions.

The interactive runtime uses lossless WOFF2 copies of Mobile Design's complete original fonts, preserving glyphs, metrics and all variable axes. Runtime dependency licenses are included in runtime/components/THIRD_PARTY_NOTICES.txt.

The sample photographs in assets/examples are unchanged, bounded art regions from Google Material Design public examples. Their original URLs, crop provenance and hashes are recorded in assets/examples/sources.json. They illustrate local content; the controls are rendered by Mobile Design.
